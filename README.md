# si253 Portfolio 

## 👋 Presentation
This project is a portfolio of practical work, screenshots, and analyses conducted in the field of cybersecurity. It brings together resources categorized by topic, covering defensive and offensive security, exploitation, web hacking, Windows/Active Directory administration, password cracking, and the use of specialized tools.

## 🗂️ Project structure

- *Defensive security* : Practical cases and investigations in defensive security (SOC, incident response, log analysis, etc.).
- *Defensive security tooling* : Use and testing of analysis and forensic tools (CyberChef, REMnux, capa, pestudio, etc.).
- *Exploitation* : Vulnerability exploitation exercises (Metasploit, CVE, Meterpreter sessions, etc.).
- *Hash cracking tools* : Password and hash cracking demonstrations (John the Ripper, SSH, etc.).
- *Offensive security tooling* : Offensive attacks and tool testing (Hydra, SQLmap, Gobuster, reverse shell, etc.).
- *Security solutions* : Implementation of security solutions (SIEM, Snort IDS, firewall rules, etc.).
- *Web Hacking* : Attacks and analyses on web applications (BurpSuite, SSRF, cookie manipulation, etc.).
- *Windows and AD fondamentals* : Windows and Active Directory administration (GPO, delegation, PowerShell, etc.).

## 🚀 Use
This project serves as documentation, inspiration and reference through concrete cases and various tools.
